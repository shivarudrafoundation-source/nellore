# UI Reference Materials

This directory serves as the visual reference database for Siva Rudra Foundations developers.

## Purpose
- Store design mockups, visual language references, screen captures, or design sheets.
- Provide a cinematic reference for typography tracking, letter-spacing, and golden accents layout alignment.
- Note: Do not copy raw code or branding text from reference materials directly into source packages. Use them only to maintain design fidelity.
